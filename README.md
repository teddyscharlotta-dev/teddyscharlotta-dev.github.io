# Teddy Scharlotta — project portfolio

Static site. No build step, no dependencies.

## Deploy to GitHub Pages

1. Create a repo named `<your-github-username>.github.io`
2. Upload every file in this folder to the repo root (keep the `images/` folder)
3. Settings → Pages → Source: `Deploy from a branch`, Branch: `main` / `root`
4. Wait ~1 minute. Site is live at `https://<your-github-username>.github.io`
5. Open that URL in a private window to confirm it is publicly visible

## Before submitting

- Replace the placeholder images in `images/` (see `images/README.txt`)
- Confirm graduation year on `index.html`
- Add your LinkedIn URL on `index.html`
- Decide which email address to list
